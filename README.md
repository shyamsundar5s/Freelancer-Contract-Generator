# Freelancer-Contract-Generator
The **Freelancer Contract Generator** is a web application designed to streamline contract creation for freelancers and clients. With predefined templates, a rich text editor, and PDF generation capabilities, users can easily create, customize, and share professional contracts.

## Features
1. **Clause Templates**:
   - Commonly used freelancer contract clauses (e.g., payment terms, deadlines, confidentiality).
   - Organized into categories for easy access and insertion.
2. **Editable Sections**:
   - Full customization of contracts using a rich text editor powered by **Toast UI**.
   - Markdown support for easy styling.
3. **Auto-Generated PDFs**:
   - Export contracts to PDF with professional layouts using **PDFMake**.
   - Customizable branding (e.g., logos, fonts, colors).
4. **Save/Share Link**:
   - Save contracts to your account or locally on your device.
   - Generate shareable links with optional password protection or expiration.
